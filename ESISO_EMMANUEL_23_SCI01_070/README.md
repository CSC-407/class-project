Beacon: Security Incident Reporting System

Beacon is a mobile-first website for reporting security incidents (theft, fire, harassment, suspicious activity and more). Reporters log in once and submit incidents. A security officer reviews every report, updates its status and leaves a note for the reporter.

Features

Reporters

Create an account and log in once. The session is remembered until they log out.
Report an incident with its type, severity (Low, Medium, High), location, date and time, and a description.
Receive a reference number (for example BCN-4821) after sending a report.
View their own reports, their current status, and any note from security.

Security officer

Dashboard showing the number of New, In Progress and Resolved reports.
Filter reports by status.
Open any report to see full details, change its status and write a note for the reporter.

How to run it
Download the three files (index.html, style.css, app.js) into one folder.
Open index.html in a browser, or open the folder in VS Code and use the Live Server extension.
For the intended view, make the browser window phone-sized (or open it on a phone).

No installation, server or database is needed.
