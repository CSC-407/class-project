# ProjectVault

**Final-Year Project Repository**

ProjectVault is a simple, responsive web platform designed to help students explore and discover academic project examples across different departments and academic years.

## Features

- Browse sample academic projects.
- Search projects by title, department, or keyword.
- Filter projects by department and academic year.
- View project details and abstracts.
- Navigate through a responsive mobile menu.
- Submit project information through a demonstration form.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)

## How to Run

1. Download or clone this project.
2. Open the project folder.
3. Locate `index.html`.
4. Open `index.html` in your web browser.

No additional installation is required.

## Project Structure

```text
projectvault/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Important Note

This project is a frontend demonstration developed for an academic assignment. It uses fictional sample project information. The submission form does not permanently store submitted information because no backend or database is connected.
